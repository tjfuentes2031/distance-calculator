# Distance Calculator

## Description
This Python program calculates the distance between two points (x1, y1) and (x2, y2) on a Cartesian plane using input values and the math module.

## How to Run
1. Open the program file in VS Code or in any other valid IDE.
2. Run the program.
3. Enter the values for x1, y1, x2, and y2.
4. Check the distance displayed on the screen.

## Input Needed
- x1
- y1
- x2
- y2

## Sample Output
Enter x1: 3

Enter y1: 5

Enter x2: 10

Enter y2: 12

The distance between the two points is: 9.90
